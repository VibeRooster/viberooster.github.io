MCP Connector

Publish a website from your agent, in one message.

Hatch is not a Claude plugin. It is a public MCP server. If your agent can add a remote Streamable HTTP connector, paste this URL — no API key, no sign-in, no vendor lock-in.

The whole product is this URL

https://mcp.theroost.dev/mcp

Add it once. Ask the agent to hatch. You get a live URL at https://your-name.theroost.dev. Per-client recipes live in the install guide.

Will it work with my agent?

We do not certify vendors. Reassurance is the protocol plus what we have actually run. If your client speaks MCP over Streamable HTTP, Hatch is the same server Claude, Cursor, and Grok already call.

AgentWhat that means
Claude, Cursor, Grok, Hermes, OpenClaw Tested We have hatched live sites from these clients.
Codex / OpenAI, Windsurf, any Streamable HTTP MCP client Expected Same transport Hatch already serves. We have not run a Hatch pass on Codex yet.
Muse New Cursor’s new model, not a separate connector. Same Hatch MCP as Cursor. We think it will work; we have not run a dedicated Muse pass yet.

Stdio-only clients can still connect through mcp-remote. That is a bridge, not a second product.

Add it

Claude Cursor Grok Hermes OpenClaw Codex Muse Windsurf Other MCP

Claude.ai & Claude Desktop

  1. Open Settings → Connectors.
  2. Click Add custom connector.
  3. Paste the URL https://mcp.theroost.dev/mcp and leave authentication set to None.
  4. Save, then fully quit and reopen Claude Desktop (a window reload isn't enough).

Custom connectors are available on Claude Pro, Max, Team, and Enterprise.

Claude Code (CLI)

claude mcp add --transport http hatch https://mcp.theroost.dev/mcp

Any stdio-only client (via mcp-remote)

If your client only speaks local stdio, bridge to the remote endpoint with mcp-remote (needs Node 20+):

{
  "mcpServers": {
    "hatch": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://mcp.theroost.dev/mcp", "--transport", "http-only"]
    }
  }
}

Tiers & limits

Free sites live 48 hours at a time. A site created through the connector is a Hatch: it goes live instantly and stays up for 48 hours. Try HITL while it lives. Perfect for demos, explorables, and "show me a URL right now."

Pin it. Ask your agent to collect payment — $4.99/yr keeps one hatch for a year. Pack it for extra storage at $4.99/yr per GB.

Roost ($259/mo) is the team plan: fair-use ephemeral hatches, 10 subscription Pins, durable HITL, unlimited members. Roost Audit ($459/mo) adds an exportable audit trail and 1-year retention. Custom domain is +$29/mo on those plans. Ask your agent to catalog then checkout — pay the URL in chat; Hatch watches for the payment.

Fair-use limits. To keep the free service healthy, new-site creation is rate-limited per hour. If your agent tells you it's been throttled, wait a little and try again.
